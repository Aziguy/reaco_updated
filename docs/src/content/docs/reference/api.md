Chaque instance sert sa propre documentation :

| URL | Contenu |
| --- | --- |
| `/api/docs/` | Documentation interactive Swagger UI, essais de requêtes compris |
| `/api/schema/` | Schéma OpenAPI 3 (YAML), pour générer un client |

En local : <http://localhost:8000/api/docs/>.

Les points d'accès, l'authentification et les limites sont décrits dans [API REST](/reaco_updated/architecture/api/).
