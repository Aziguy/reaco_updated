## La pile en un coup d'œil

<CardGrid>
  <Card title="Django 5.2 LTS et HTMX" icon="seti:python">
    Rendu côté serveur, interactions partielles avec HTMX, aucun framework JavaScript. Python 3.13, dépendances gérées par uv.
  </Card>
  <Card title="Données ouvertes" icon="open-book">
    Open Prices, Open Food Facts, ADEME Impact CO2, Anses Ciqual et IGN, derrière un client HTTP commun tolérant aux pannes.
  </Card>
  <Card title="Tailwind CSS v4" icon="seti:css">
    Styles compilés depuis `assets/app.css`, composants déclarés en `@utility`, CSP stricte sans script ni style en ligne.
  </Card>
  <Card title="Docker et CI" icon="rocket">
    Image multi-étapes, Docker Compose avec Caddy en production, CI GitHub Actions (lint, tests PostgreSQL, `check --deploy`, image).
  </Card>
</CardGrid>
