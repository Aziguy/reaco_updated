Sécurité du compte

La carte Sécurité du compte du profil rassemble la double authentification, le mot de passe et les adresses email.

{% guide_figure "security" %}

Avec la double authentification, un mot de passe ne suffit plus pour entrer dans votre compte : il faut aussi votre téléphone ou votre appareil.

  • Application d'authentification : cliquez sur Activer, confirmez votre mot de passe, scannez le QR code avec Google Authenticator, Microsoft Authenticator ou 1Password, puis saisissez le code à 6 chiffres affiché.
  • Clé d'accès : cliquez sur Ajouter et validez avec l'empreinte, le visage ou le code de votre appareil. Vous pourrez ensuite vous connecter avec Se connecter avec une clé d'accès, sans mot de passe.
  • Codes de secours : dix codes à usage unique, créés à l'activation. Téléchargez-les et gardez-les hors de votre téléphone.

À la connexion suivante, Comégusto demande le code de l'application (ou votre clé d'accès). Vous pouvez faire confiance au navigateur pendant deux semaines pour ne pas le saisir à chaque fois.

La double authentification demande une adresse email confirmée. Si besoin, renvoyez le lien depuis Adresses email.

Supprimer son compte

La suppression est définitive : garde-manger, listes de courses et favoris sont effacés. Une confirmation vous est demandée avant toute suppression.
